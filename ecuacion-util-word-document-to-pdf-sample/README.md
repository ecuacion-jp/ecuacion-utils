# ecuacion-util-word-document-to-pdf-sample

## What is it?

Sample code for [`ecuacion-util-word-document-to-pdf`](../ecuacion-util-word-document-to-pdf).

The `pom.xml` in this project also serves as a reference for dependency setup.

## Sample Classes

| Class | Description |
| --- | --- |
| `ContractToPdfSample` | Converts a contract written in Word (`test-data/contract.docx`) to PDF using `WordToPdfUtil`, with system fonts and with a font file |

`test-data/contract.docx.pdf` is the PDF file Word for Mac exported from the same file, for comparison.
